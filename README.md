# Swanton Village Weather

Initial website for **SwantonWX.com**, serving Swanton Village, Vermont.

## Planned features
- Live Davis Vantage Pro2 / Vue weather conditions
- Weather Underground station KVTSWANT4 integration
- National Weather Service forecasts and alerts
- Weather history and graphs
- Historical weather records
- Snowfall tracking
- Live weather camera
- Storm updates and weather blog

## Files
- `index.html` — homepage
- `styles.css` — responsive site design
- `app.js` — JavaScript/data integration foundation

This first version intentionally uses placeholders for live data. API credentials should never be committed directly to this public repository.
